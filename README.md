# 🎮 2D Platform Game – JavaFX

## Project Overview

A 2D platform game developed using Java and JavaFX as part of an academic programming project at Hacettepe University.

The project focuses on object-oriented programming, interactive game design, and game mechanics.

## Technologies

- Java
- JavaFX
- IntelliJ IDEA

## Game Design

- Player movement and keyboard controls
- Gravity and jumping mechanics
- Apple collection and obstacle avoidance
- Collision detection
- Sprite animation
- Score management

## Technical Concepts

- Object-Oriented Programming (OOP)
- Inheritance and Polymorphism
- Abstraction
- Event-Driven Programming
- Game Loop
- File Handling

## Academic Context

Developed for the Introduction to Programming Laboratory II (BBM104) course in Spring 2026.

Starter code and game assets were provided as part of the course.
